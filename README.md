## ⚙️ Engineering highlights

- **Concurrency & performance:** Java 21 virtual threads, multi-tier Caffeine caching, indexed queries with fetch joins to avoid N+1.
- **Algorithms:** text clustering with Jaccard similarity, weighted credibility scoring, Persian text normalization.
- **Applied AI:** a 5-layer pipeline that combines a local VLM with deterministic rules and validation, so sensitive financial data never leaves the organization's network.
- **SEO & delivery:** structured data (JSON-LD), prerendering for crawlers, Nginx tuning.
